pbfcut online

Cut an OpenStreetMap .osm.pbf file into map tiles. The cut runs in your browser: the file is not uploaded. Manual · Source

1. The input file

The list of download.geofabrik.de.

Download

Get puts the file into the storage of this site, and the cut uses it. Download saves the file on your computer: then select it in "A file on this computer".

2. The settings

A GeoJSON Polygon or MultiPolygon. With no boundary, the tiles cover the bounding box of the file.
